# Web Responsive

Responsive web client for Odoo 19 Community, community-supported (based on the
OCA `web_responsive` module).

## Features

**All devices**

- Redirect to the dashboard after logging in (enable *Redirect to Home* in the user profile)
- Fullscreen app menu with new navigation
- Quick menu search inside the app menu
- Sticky header & footer in list view
- Sticky statusbar in form view
- Bigger checkboxes in list view

**Mobile**

- View type picker displayed as a comfortable dropdown
- Control panel buttons use icons to save space
- Followers and send button visible on mobile
- Big inputs on form in edit mode

**Desktop**

- Keyboard shortcuts using `Alt + Shift + [NUM]` (e.g. `Alt + S` for Save)
- Autofocus on the search box when opening the app menu
- Side-by-side document viewer when the chatter is on the side
- Distinct composer color for public messages vs internal log notes

See `readme/` for the full OCA documentation with screenshots.
